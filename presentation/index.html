Problem Statement & Cloud-Native Solution

2 / 11

Legacy Operational Bottlenecks

  • ✕ Manual Library Circulation Delays
    Paper-based student checkouts create lending queues, inventory discrepancies, and untracked overdue book returns.
  • ✕ Fragile Monolithic Deployments
    Host port collisions (e.g. Postgres port 5432), environment drift between dev and staging, and single-point-of-failure outages.
  • ✕ Blindspot Operations
    Zero telemetry into API request latency, database query bottlenecks, or memory saturation during exam periods.

Cloud-Native Solution Architecture

  • ✔ Containerized Microservices
    Decoupled FastAPI backend and React 18 frontend running non-root containers with persistent PostgreSQL storage.
  • ✔ Automated Quality & Security Gates
    Pre-push secret scanners, 16/16 Pytest blocking tests, and automated Trivy container vulnerability scanning in CI.
  • ✔ Declarative Kubernetes & Helm
    Self-healing 2-replica deployments, NGINX Ingress traffic routing, and dynamic Horizontal Pod Autoscaling (HPA).
