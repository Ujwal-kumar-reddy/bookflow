Context & Objectives

Problem Statement & Solution Architecture

2 / 10

The Problem Space

  • Campus Library Bottleneck Manual checkout registers result in lending latency, misplaced student records, and untracked overdue books.
  • Fragile Legacy Deployments Host port conflicts (5432 collision), environment drift, and single-point-of-failure outages during peak campus hours.
  • Zero Operational Visibility No telemetry into API request latency, database query bottlenecks, or container resource exhaustion under load.

The Cloud-Native Solution

  • Containerized Microservices Decoupled FastAPI backend and React frontend running non-root containers with PostgreSQL persistence.
  • Automated Security & Test Gates Pre-commit secret scans, 16/16 Pytest tests, and Trivy CVE scanning in GitHub Actions.
  • Declarative Kubernetes & Helm Self-healing 2-replica deployments, NGINX Ingress traffic routing, and dynamic Horizontal Pod Autoscaling (HPA).
  • Continuous Real-Time Telemetry Prometheus metrics harvesting paired with a 4-panel live Grafana observability dashboard.

Automation Pipeline

Continuous Integration & Delivery (GitHub Actions)

6 / 10

Three-Stage CI/CD Architecture

  • Stage 1: Automated Quality Gate Executes 16/16 Pytest unit tests and validates frontend Vite production bundling. Failure aborts the pipeline.
  • Stage 2: Trivy Container Vulnerability Scan Scans both backend and frontend images. Strictly fails with exit-code 1 on HIGH or CRITICAL CVEs (0 detected).
  • Stage 3: Immutable GHCR Publishing Pushes images to GitHub Container Registry tagged with Git commit SHA (e.g. backend:1ff6ddf) for complete auditability.
